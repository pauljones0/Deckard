Deckard 0.6.0 adds native-resolution, source-timed animation across the supported controllers. Auto retains GIF frame delays, including 100 FPS sources, and probes video rates such as 29.97/60 FPS. Per-media and per-device animation caps are configurable from Auto through 120 FPS; there is no fixed 33 ms render loop.

Rendering overlaps one in-flight USB transfer with one queued frame. Backpressure bounds work and memory, while configuration replacement retains a fair full-key sweep. Active writes use nonblocking input polling, interruptible idle waits, borrowed encoded bytes and reused packet buffers. Static compositions and endpoint-sized media avoid unnecessary copies, and JPEG encoder state persists across frames. Preview updates wake on pixel changes and follow desktop vsync.

Model geometry uses validated firmware reports where available. Mini remains 80×80, Plus XL is consistently 112×112 with a 1200×100 logical strip, and Studio's fallback is 144×112. Size/playback-aware asset caching preserves SVG and video detail on larger strips and applies FPS/loop changes. Oversized artwork grids have a pixel budget.

The release retains all 56 built-in OS, Deck, Media, OBS and VolumeMixer replacements and the executable plugin API. Linux bundles include FFmpeg and FFprobe, audio/input helpers and the native example plugin, with no Python/GTK runtime. AppImage, DEB, RPM and portable builds target x86_64 and aarch64; Arch has a PKGBUILD. The GUI supports Vulkan with automatic OpenGL fallback, X11 and Wayland, with glibc 2.35+.

[Endpoint specifications and diagnostics](rendering-endpoints.md) explain the distinction between simulated rendering FPS, completed USB writes and physical panel refresh. Software benchmarks cannot certify maximum visible FPS on an unconnected controller.
